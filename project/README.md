## What is this?
For my project I wanted to make a simple, yet enjoyable, recreation of a snake game. The core idea of the game follows the original concepts for a snake game with a theme of gummyworms.

## What does it do?
The game functions with scorekeeping, powerups, and slowly increasing difficulty. 

## How far did I get?
I believe the game has reached what I'd consider the "minimum viable product."

## What AI Tools did I use?
I started with using Claude, however it quickly ran out of tokens so I had to switch to Gemini.
